Live Activities

Everything lives in one pill.

Persistent, expandable activities and transient alerts — compact when idle, fluid when it matters.

Now Playing

Album artwork from the media session, iTunes Search API fallback, marquee track info, smoothed equalizer bars, playback controls and an interactive seek bar — all inside one compact pill that expands fluidly when you need it.

Mic Privacy Dot

A subtle indicator appears whenever an app is accessing your microphone. Privacy at a glance — no pop-ups, no noise.

Transient HUD

Auto-dismissing alerts for volume changes, Caps / Num Lock, charger plug & unplug, low battery and Bluetooth connections — with battery level when reported.

Beautiful Design

Apple-inspired aesthetics adapted for the desktop: glassy black pill, fluid spring motion, compact ⇄ expanded morphing and elegant micro-interactions that feel native to Windows 11, not bolted on.

Engineering

Built like it belongs there.

Hardware-accelerated, spring-driven and tunable down to the last curve.

Adaptive placement

Top taskbar: embeds into it and expands downward. Bottom, left or right: floats as an independent pill with spring animations.

Fluid spring physics

Compact ⇄ expanded morphing driven by cubic-bezier(0.34, 1.3, 0.5, 1) — the same overshoot feel as the real thing.

GPU rendering

Direct2D + DirectWrite in a layered window. Around 30 FPS when active, silent when not.

Fully tunable

Font family, weight and size, HUD toggles, idle visibility, media visibility policy, animation and debug hotkeys.

Smart artwork

Album art flows from the Windows media session (GSMTC) to the iTunes Search API to a graceful placeholder gradient.

Debug hotkeys

Ctrl+Win+1…9, 0 to poke at animation states and internals in real time — no restarts, no recompiles.

Installation

Up and running in a minute.

1

Install Windhawk

Grab it from windhawk.net — the mod platform for Windows.

2

Create a new mod

Open Windhawk → Create a new mod (or “Explore” → new mod editor).

3

Paste the mod source

Replace the template with the contents of win11-dynamic-island.wh.cpp.

4

Compile & enable

Windhawk compiles it on the spot with its bundled LLVM/MinGW toolchain (C++23).

5

Customize

Open Settings in the mod editor to tune behavior to your taste.

Requirements. Windows 10 (1809+) or Windows 11. Media controls use the Windows media session API (GSMTC); album art falls back to the iTunes Search API when the session provides none.
Standalone syntax check — the mod is compiled by Windhawk itself, but you can verify it manually: 
# syntax-only check with clang
clang++ -fsyntax-only -std=c++23 -target x86_64-w64-mingw32 \
  -DUNICODE -D_UNICODE -D_WIN32_WINNT=0x0A00 -DWH_MOD \
  -include windhawk_api.h win11-dynamic-island.wh.cpp
